A 4 KB Python chess engine: 0x88 board, full legal move generation, alpha-beta with iterative deepening, transposition table, quiescence search, null-move pruning and LMR. Node-count limited for deterministic replay. Practice Elo ~1,307 (mean of 3 trials), above the 1,154 entry floor.

## Run it

```sh
python3 main.py
```
